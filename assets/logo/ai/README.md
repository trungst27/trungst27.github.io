# AI logo assets

Static image files for the AI tools and agents row. The page displays eight
selected logos in one responsive row; additional downloaded assets are available here.
This is a curated selection, not a complete directory of every AI product.

## Sources

- Most SVGs: [Lobe Icons](https://github.com/lobehub/lobe-icons),
  `@lobehub/icons-static-svg` version `1.102.0`, downloaded from
  `https://cdn.jsdelivr.net/npm/@lobehub/icons-static-svg@1.102.0/icons/`.
  The MIT license is included in `LICENSE-LobeHub.txt`.
- `pi-harness.svg`: [Pi's official logo](https://pi.dev/logo-auto.svg).
  This is the Pi coding agent from pi.dev, not Inflection's Pi assistant.
- `deepseek-harness.svg`: [DeepSeek Harness's official favicon](https://www.deepseek.com/harness/favicon.svg).
- `autoglm.svg`: [AutoGLM's official favicon](https://autoglm.zhipuai.cn/favicon.svg?t=20250809).
- `nami.png`: [Nami AI's official favicon](https://p1.ssl.qhimg.com/t110b9a9301862eed9fa4f0efd9.png),
  linked by [n.cn](https://n.cn/).
