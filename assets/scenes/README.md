# After Hours scene

`after-hours.jpg` and `after-hours-small.jpg` are variants of a scene generated specifically for Teung’s Home using OpenAI’s built-in Imagegen tool on 2026-11-14. They are not downloaded from the researched asset packs.

The input reference was the After Hours UI mockup approved in the conversation. Imagegen produced a fresh scene-only image with the rainy window, desk lamp, record player, bamboo, noodles and headphones. Avatar, text, logos and controls were excluded from the scene; those remain live website elements.

Generated original: `exec-e503b3af-6c15-4310-83c9-0f71e355d60c.png` (1536 × 1024). The original remains in the local Imagegen output folder. JPEG variants were encoded at quality 88 using Windows System.Drawing; the smaller variant is 960 × 640. No new compression library was installed.

Prompt summary: clean background plate matching the approved forest/amber nighttime desk, quiet dark space on the left for HTML profile, detailed rainy-window desk on the right; no people, animals, text, UI, frames or logos.

The JPEGs remain still images. `assets/js/room-ambience.js` adds original procedural canvas material above them: moving window rain, noodle-bowl vapour, and a local warm light. It uses source-image coordinates and follows the CSS crop; this is a live composition, not a generated video. The preview GIF under ignored `.impeccable/review/` is a recording of real browser screenshots encoded with Windows WPF, not a shipping background asset.
